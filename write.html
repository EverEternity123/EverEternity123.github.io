写作台

连上你的 GitHub 仓库之后，就能在手机上直接写文章。保存会提交到仓库，网站大约 1 分钟后自动更新。

还没配置仓库。打开 write.config.js， 把 owner 和 repo 填上你的 GitHub 用户名和仓库名，提交后刷新本页。
这台设备上还存着旧版的明文令牌，设个密码把它加密保存吧。

令牌会用你设的密码加密（PBKDF2 + AES-GCM），只存在这台设备的浏览器里， 不会上传到任何地方。以后打开写作台只输密码就行。

令牌已经加密存在这台设备上，输密码就能解开。

怎么拿到这个令牌？
  1. 手机上打开 github.com/settings/personal-access-tokens/new （需要先登录 GitHub）
  2. Token name 随便填，比如 everternity-blog
  3. Expiration 选一个期限，比如 1 年
  4. Repository access 选 Only select repositories， 只勾选放博客的那个仓库
  5. 展开 Repository permissions，找到 Contents， 改成 Read and write
  6. 点最下面 Generate token，复制生成的 github_pat_… 贴到上面

这个密码只保护「存在这台设备上的令牌」，它不等于网站登录，也拦不住别人拿到你的令牌。 令牌等同于仓库的写权限，别分享给别人；换设备需要重新贴一次。
